🔧 Available Management Scripts

🚀
bootstrap-control-plane.sh
Initial setup - Install Kubernetes, storage, monitoring, and GitOps
sudo ./scripts/installation/bootstrap-control-plane.sh
➕
add-worker-node.sh
Add more machines to your cluster for increased capacity
sudo ./scripts/nodes/add-worker-node.sh
🌐
setup-edge-node.sh
Configure VPS as edge node for public access
sudo ./scripts/setup/setup-edge-node.sh
💻
setup-laptop.sh
Configure management laptop with kubectl and access
sudo ./scripts/setup/setup-laptop.sh
📊
cluster-status.sh
Check cluster health, nodes, pods, and resources
./scripts/operations/cluster-status.sh
🔑
show-credentials.sh
Display service URLs and login credentials
sudo ./scripts/utils/show-credentials.sh
🛠️
create-app.sh
Scaffold new application with manifests and configuration
./scripts/operations/create-app.sh myapp
🤖
deploy-llm-chat.sh
Deploy local AI chat (Open WebUI + Ollama)
sudo ./scripts/deploy-llm-chat.sh
🔒
enable-security-hardening.sh
Apply production security policies and encryption
sudo ./scripts/setup/enable-security-hardening.sh
