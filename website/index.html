Get Started in 3 Steps

1

Run Interactive Setup

One command sets up everything. Works on any machine with Ubuntu 24.04 LTS.

git clone https://github.com/vinsac/MyNodeOne.git cd MyNodeOne sudo ./scripts/installation/install-mynodeone.sh
2

Bootstrap Your Cluster

Installs Kubernetes, storage, monitoring, and GitOps in ~20 minutes.

sudo ./scripts/installation/bootstrap-control-plane.sh
3

Deploy Your Apps

Push to Git and ArgoCD automatically deploys. Or use our one-click app installer.

./scripts/operations/create-app.sh myapp --domain myapp.com sudo ./scripts/apps/install-jellyfin.sh # One-click apps
