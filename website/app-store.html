🚀 One-Click Installation

Choose from our curated collection of popular self-hosted applications. Each app is pre-configured for MyNodeOne with automatic SSL, storage provisioning, and networking.

📋 Installation Requirements:

  • SSH into your control plane first
  • Navigate to the MyNodeOne repository
  • Run the installation command shown in the popup
  • Each app includes automatic SSL, storage, and networking
  • Apps are monitored and can be managed through the dashboard
